# AI Usage Policy

A human must be responsible for all contributions to this project. We accept code that was written by coding agents but contributors are expected to understand and verify all the code in their contribution. No fully automated contributions are accepted.

We do not accept AI generated images, illustrations or art. We do not accept AI written or edited prose for our knowledge base, guides and FAQs. That includes localisations and translations.

There is currently no active usage of machine learning, LLMs or AI as features in any of the tools made and maintained by conservation.tv. While this isn't a rule, there must be a very good reason and requirement to include these technologies, and even then they must always be optional. Open a discussion if you have a proposal for features that use these technologies.
