# Review

`review.tools.conservation.tv/pr/<number>`: a pull request, read the way this repository is built. Generated code is
committed so every change to it can be seen, which leaves GitHub's diff mostly generated: a route change arrives with
its API document, the SDK and CLI regenerated from it, and Drizzle's schema snapshots. This shows the same pull request
with what to read first and what was generated from it set apart.

It is a Cloudflare Worker (Hono) serving a React app, built with the Cloudflare Vite plugin, and draws diffs and the
file tree with [Pierre](https://pierre.computer)'s [`@pierre/diffs`](https://diffs.com) and `@pierre/trees`. It reads
only what GitHub shows anyone: the pull request, its files, comments, reviews, checks, mergeability and the pull
requests around it. Nothing is written back; replies link to GitHub.

## Pages

| Path                 | Shows                                                                              |
| -------------------- | ---------------------------------------------------------------------------------- |
| `/`                  | Open pull requests, each stack's members together, and the recently closed ones    |
| `/pr/<number>`       | Its description and conversation, merge state and signoffs, contract changes       |
| `/pr/<number>/files` | Every changed file: source code open, generated files folded, line comments inline |

## Kinds of file

Each changed file is one of these ([`src/shared/classify.ts`](src/shared/classify.ts)), in reading order:

| Kind          | Files                                                                    | Shown  |
| ------------- | ------------------------------------------------------------------------ | ------ |
| Source code   | Everything else                                                          | Open   |
| Migrations    | `drizzle/*/migration.sql`, unless umbrella generated it                  | Open   |
| API contracts | `contracts/openapi.json` and its release snapshots                       | Folded |
| Generated     | SDKs and CLIs, MediaMTX's client, Drizzle snapshots, umbrella's policies | Folded |
| Lockfile      | `pnpm-lock.yaml`                                                         | Folded |

A file added whole whose first line names its generator (`-- Generated by …`) is generated wherever it is. Keep the
rules in step with the generated paths `oxlint.config.ts` ignores.

The generated files are trusted on the strength of `signoff/generated`: `pnpm signoff:generated` regenerates every
API document, SDK and CLI and signs off only if nothing changed, so a green signoff on the head commit means each
generated file is what its generator writes. Read the generator's input instead.

## API contracts

Each changed `contracts/openapi.json` is compared at the merge base and the head with
`@conservationtv/versioned-api/contracts/compare`, the comparison the `contracts` check runs: a new operation version
is **added**; a version that already existed and now differs in its inputs, outputs, security or location is
**changed**, and one that is gone is **removed**. Both break clients that require that version.

## GitHub

The Worker reads GitHub's REST API with `GITHUB_TOKEN`, a fine-grained token with read-only access to public
repositories and no other permission. Responses are kept in the Cache API and revalidated with their ETags, which with a
token costs nothing against the rate limit. Without one, GitHub allows 60 requests an hour from an address, counting
revalidations, so cached copies serve ten times longer; a pull request takes about ten requests.

## Development

```sh
cp .dev.vars.example .dev.vars   # and set GITHUB_TOKEN, or leave it empty
pnpm dev                         # http://localhost:5177
pnpm typecheck
```

## Deploying

The Worker runs on the conservation.tv Cloudflare account (`0def86f2…`, set by the `deploy` script, so it never lands
on another account the CLI is signed in to), on `review.tools.conservation.tv`. Cloudflare issues that hostname its
own certificate: the zone's universal one covers only one level below `conservation.tv`.

```sh
pnpm run deploy                                    # build and deploy
pnpm exec cf workers secrets update GITHUB_TOKEN   # replace the token
```

A Worker that does not exist yet cannot be deployed without its secret: the first deploy passed it with
`--secrets-file`.

## Pull request links

`.github/workflows/review-link.yml` appends each new pull request's review link to its description.
